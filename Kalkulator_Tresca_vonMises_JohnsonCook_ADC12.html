Kalkulator Eksakta Proses Manufaktur

Analisis tegangan luluh menggunakan kriteria Tresca dan von Mises, serta model konstitutif Johnson–Cook standar dan termodifikasi untuk studi kasus pemesinan paduan aluminium ADC12.

Catatan pemodelan: Tresca dan von Mises adalah kriteria luluh berbasis keadaan tegangan. Johnson–Cook adalah model konstitutif tegangan alir yang bergantung pada regangan plastis, laju regangan, dan temperatur. Ketiganya saling melengkapi, tetapi bukan persamaan yang dapat saling menggantikan. Nilai bawaan ADC12 di bawah berasal dari artikel Meng et al. (2020); kondisi tegangan utama dan kondisi proses pada contoh awal adalah input latihan yang dapat diubah.

1. Keadaan tegangan — Tresca & von Mises

Masukkan tegangan utama pada satu titik material. Satuan seluruh tegangan adalah MPa.

Tresca: τmaks = (σmaks − σmin)/2; luluh jika τmaks ≥ σᵧ/2.
von Mises: σVM = √{[(σ₁−σ₂)²+(σ₂−σ₃)²+(σ₃−σ₁)²]/2}
Catatan: σ₁, σ₂, σ₃ harus merupakan tegangan utama yang diurutkan atau tidak; kalkulator mengurutkannya secara otomatis.

2. Parameter material ADC12

Parameter Johnson–Cook klasik yang dilaporkan artikel open access.

Parameter A, B, n, C, m, temperatur lebur, serta bentuk persamaan mengikuti artikel ADC12. ε̇₀ = 0,0003 s⁻¹ digunakan sebagai kondisi referensi yang ditunjukkan pada pemodelan pengerasan regangan penelitian.

3. Kondisi proses / input perhitungan

Semua kondisi dapat diubah untuk mengevaluasi skenario pembentukan atau pemesinan.

JC standar: σ = (A + Bεₚⁿ)[1 + C ln(ε̇/ε̇₀)][1 − (T*)ᵐ]
T* = (T − T₀)/(Tₘ − T₀)
Model klasik memerlukan ε̇/ε̇₀ > 0 dan 0 ≤ T* ≤ 1 untuk interpretasi fisik lazim. Kalkulator memberi peringatan jika input berada di luar rentang tersebut.

4. Model Johnson–Cook termodifikasi ADC12

Mengikuti fungsi bertahap dan polinomial yang dipublikasikan Meng et al. (2020).

Kε = { 1 + 2,65 εₚ0,95168, 0,0067 < εₚ ≤ 0,039
1 + 0,796 εₚ0,57396, 0,039 < εₚ < 0,067 }
Kε̇ = 1 − 0,27108 ln(ε̇*) + 0,0164[ln(ε̇*)]²
KT = 1,97074 − 1,054×10⁻²T + 7,52433×10⁻⁵T² − 2,21592×10⁻⁷T³ + 2,16767×10⁻¹⁰T⁴
σmod = A × Kε × Kε̇ × KT

Di luar interval regangan yang dipublikasikan, kalkulator tidak melakukan ekstrapolasi diam-diam; hasil model termodifikasi ditandai tidak tersedia.
